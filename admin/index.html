Admin du portfolio

Connecte-toi avec un jeton GitHub pour modifier et publier le site directement. Le jeton reste dans ce navigateur et n’est envoyé qu’à GitHub.

Créer le jeton (2 minutes)
  1. Ouvre GitHub › Settings › Fine-grained tokens › Generate new token.
  2. Expiration : 90 jours. Resource owner : ton compte.
  3. Repository access : Only select repositories › .
  4. Permissions › Repository › Contents : Read and write (Metadata : read est ajouté automatiquement).
  5. Clique sur Generate, copie le jeton et colle-le ici.
