ShadowFactory – Red Team vs Blue Team

Cybersécurité · SOC · Cloud · R&D

ShadowFactory – Red Team vs Blue Team

Overview

Full-stack industrial cybersecurity simulation: a Red Team executes multi-phase attacks on a multi-VM environment simulating an industrial plant (IT + OT), while a Blue Team SOC built on Oracle Cloud Infrastructure (Wazuh, TheHive 5, Shuffle SOAR) monitors, detects and auto-responds in real time.

Key Features

  • Full SOC stack on OCI: Wazuh SIEM, TheHive 5 case management, Shuffle SOAR automation
  • Multi-VM environment simulating IT (Windows Server AD, Linux workstations) and OT (PLC via Modbus)
  • 5 attack phases: network scanning, SQL injection, Active Directory lateral movement, OT pivoting, PLC manipulation via Modbus
  • 15 custom Wazuh detection rules mapped to each attack phase
  • Automated SOAR workflow: alert → IP block via iptables → incident case in TheHive
  • IT/OT network segmentation with dedicated VLAN and DMZ

Technologies

OCI Wazuh TheHive 5 Shuffle SOAR Modbus iptables Kali Linux Metasploit Python Active Directory
LinkedIn post (PDF) PDF presentation
Team Taobata SIMPORÉ, Abdoul-Moumouni DIALLO, Daniel KUNAKA, Otman DAKACH · Supervisor: Prof. Younes WADIAI

Présentation

Simulation complète de cybersécurité industrielle : une Red Team mène des attaques en plusieurs phases sur un environnement multi-VM simulant une usine (IT + OT), tandis qu’un SOC Blue Team déployé sur Oracle Cloud Infrastructure (Wazuh, TheHive 5, Shuffle SOAR) surveille, détecte et répond automatiquement en temps réel.

Fonctionnalités clés

  • Stack SOC complète sur OCI : SIEM Wazuh, gestion des incidents avec TheHive 5, automatisation avec Shuffle SOAR
  • Environnement multi-VM simulant l’IT (Windows Server AD, postes Linux) et l’OT (automate PLC via Modbus)
  • 5 phases d’attaque : scan réseau, injection SQL, mouvement latéral dans Active Directory, pivot vers l’OT, manipulation de l’automate PLC via Modbus
  • 15 règles de détection Wazuh personnalisées, associées à chaque phase d’attaque
  • Workflow SOAR automatisé : alerte → blocage de l’IP via iptables → dossier d’incident dans TheHive
  • Segmentation réseau IT/OT avec VLAN dédié et DMZ

Technologies

Brainwave Internship Projects

Cybersécurité · Python · ML

Projets de stage Brainwave

Overview

Two cybersecurity tools developed during a Brainwave Matrix internship. A Phishing URL Scanner using a Scikit-learn ML classifier exposed as a Flask API, and a Password Strength Checker with real-time OWASP feedback built with Streamlit.

Tool 1: Phishing URL Scanner

  • ML classifier trained on phishing URL datasets
  • Feature extraction: URL length, domain age, HTTPS, redirects
  • Flask REST API returning JSON with a confidence score
  • Interactive web UI for real-time URL checks

Tool 2: Password Strength Checker

  • Shannon entropy calculation for password strength
  • Common-pattern and dictionary attack detection
  • OWASP compliance scoring in real time
  • Streamlit interactive dashboard with visual feedback
